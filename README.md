# pkmn-dmg-calc

Simple calculator app for the CLI using Node.

Input the type you're attacking with, and the two types that are being attacked ("None" is an option for the second defending 
type, so that will be used for the purposes of attacking monotype Pokemon).

## How to Run

Clone this repository to your target directory and run `npm install` to install dependencies. Once finished, just run `node index.js`
to run the application.

## Additional Notes

Application may not work properly on outdated versions of Node. Recommended to use version 22+.
